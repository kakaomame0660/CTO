# MAMA 自己相関クロス（相互監視）インジケーター

NEGI（@negixnegi）さんの「MA の MA（自己移動平均線）」の考え方をそのままインジケーターにしたものです。
TradingView 用（Pine Script v6）と MT5 用（MQL5）のインジケーター、TradingView 用のバックテスト用ストラテジーがあり、ロジックは共通です。

| ファイル | 対象 |
| --- | --- |
| `MAMA_SelfCross.pine` | TradingView |
| `MAMA_SelfCross.mq5` | MetaTrader 5 |
| `MAMA_SelfCross_Strategy.pine` | TradingView（バックテスト用ストラテジー） |
| `MAMA_SelfCross_Compare.pine` | TradingView（設定比較：最大 45 通りを一度に検証して表で並べる） |
| `MAMA_SelfCross_EA.mq5` | MT5（検証用 EA：ストラテジーテスターでリアルティック検証。初期設定では本番口座では発注しない） |

> ※ ここでいう MAMA は「MA の MA」です。Ehlers の MESA Adaptive Moving Average（MAMA）とは別物です。

---

## 考え方

| 用語 | 意味 | 既定の色 |
| --- | --- | --- |
| 短期MA | 5MA | マゼンタ |
| 短期MAMA | 5MA に、さらに 5MA をかけた線 | シアン |
| 長期MA | 20MA | 緑 |
| 長期MAMA | 20MA に、さらに 20MA をかけた線 | 黄 |
| トレンドMA | 200MA | オレンジ |

- **自己相関クロス**：同じ期間の MA と MAMA のクロス。
  - **小矢印** = 短期（5MA × 5MAMA）
  - **大矢印** = 長期（20MA × 20MAMA）
- **相互監視**：2 つの自己相関クロスの向きが揃ったら、その方向にエントリー。エントリー後に逆向きのクロスが出たら終了。
  - **小→大（大きく取る）**：小矢印が出ている状態で、同じ向きの大矢印を待って入る
  - **大→小（細かく取る）**：大矢印が出ている状態で、同じ向きの小矢印を待って入る
- **トレンドに逆らわない**：200MA より上なら買いだけ、下なら売りだけ、のようにフィルターできます。
- **パターンB**：短期MAMA と 長期MA のクロス（5MAMA × 20MA）。5MA より遅れるぶん、入った直後の戻しを食らいにくい。絶対クローズ条件は逆クロス。
- **期間**：5 と 20 は 40・60・80・100… と共通の倍数が多く「つぶしが効く」。5 と 100 にしても考え方は同じで、周期が長くなるだけです。

| 表示 | TradingView | MT5 |
| --- | --- | --- |
| 小矢印（短期の自己相関クロス） | ⇧ ⇩ | ⇧ ⇩（中抜き矢印） |
| 大矢印（長期の自己相関クロス） | 太矢印 | 太矢印 |
| エントリー（相互監視で向きが一致） | 「買い」「売り」ラベル | ●（青 = 買い／赤 = 売り） |
| 決済（逆クロス） | ✕ | ✕ |

| 状態パネル | 右上の表 | 右上のテキスト |

状態パネルには「小・大それぞれの向き／相互監視が一致しているか／トレンド／いまのポジション」が出ます。

## 設定

### 移動平均

| 項目 | 既定 | 説明 |
| --- | --- | --- |
| 短期 期間（小矢印） | 5 | |
| 長期 期間（大矢印） | 20 | 100 などにすると周期が長くなる |
| MA の種類 | SMA | SMA / EMA / SMMA / WMA（LWMA） |
| MAMA の種類 | MA と同じ | MAMA だけ別の種類にもできる |
| トレンドMA | 200 | MT5 では 0 にすると使わない |

### シグナル（相互監視）

| 項目 | 既定 | 説明 |
| --- | --- | --- |
| エントリー方式 | 両方 | 両方 / 小→大（大きく取る） / 大→小（細かく取る） |
| 決済条件 | 自動 | 下の表を参照 |
| トレンドフィルター | OFF | OFF / 価格がトレンドMAの上なら買いのみ・下なら売りのみ / トレンドMAの傾きの方向のみ |
| 確定足で判定 | ON | ON だと足が確定してからシグナルを出す（リペイントしない） |

決済条件の選択肢：

| 選択肢 | 動き |
| --- | --- |
| 自動（既定） | 大矢印で入ったら長期の逆クロスまで持つ。小矢印で入ったら、どちらかの逆クロスで終了 |
| どちらかの逆クロス（原典ルール） | 「エントリーしてからどっちかの MA で逆向きクロスが出たら終了」そのまま |
| 長期（大）の逆クロスのみ | 大きく取りたいとき |
| 短期（小）の逆クロスのみ | |

「小→大」で入っても決済が「どちらかの逆クロス」だと、次の小矢印ですぐ終了になります。大きく取りたいなら「自動」か「長期のみ」を使ってください。

### おすすめの組み合わせ

| やりたいこと | エントリー方式 | 決済条件 |
| --- | --- | --- |
| 大きく取る | 小→大 | 自動 または 長期のみ |
| 細かく取る | 大→小 | 自動 または どちらか |
| 原典どおり | 両方 | どちらかの逆クロス |

## バックテスト（TradingView ストラテジー）

`MAMA_SelfCross_Strategy.pine` はインジケーターと同じロジックで実際に売買し、ストラテジーテスターで成績を確認できます。

### 使い方

1. Pine エディタに `MAMA_SelfCross_Strategy.pine` を貼り付けて「保存」→「チャートに追加」
2. チャート下部の「ストラテジーテスター」で成績（損益・勝率・PF・最大ドローダウン・取引一覧）を確認
3. チャート右下にも簡単な成績パネル（取引回数・勝率・PF・純利益・最大DD）が出ます

### 設定

| 項目 | 既定 | 説明 |
| --- | --- | --- |
| 手法 | 相互監視 | 相互監視（自己相関クロス） / パターンB（短期MAMA × 長期MA） / パターンC（短期MA × 長期MA、普通のゴールデンクロス・デッドクロス）。B・C は逆クロスでドテン |
| 売買方向 | 両方 | 両方 / 買いのみ / 売りのみ |
| トレンドフィルター | OFF | インジケーターと同じ |
| エントリー方式・決済条件 | 両方・自動 | インジケーターと同じ（相互監視のとき） |
| 損切り | 直近の安値・高値 | なし / 直近の安値・高値 / ATR 倍。「直近の安値・高値」はサインが出た足を含む直近 N 本（既定 10 本）の最安値（売りは最高値）に損切りを置き、割ったら損切り。位置はエントリー時に固定 |
| 損切りの余裕 | 0 ティック | 安値ちょうどではなく少し外側に置きたいときの幅 |
| 利確 | 0（なし） | ATR の何倍で利確するか。0 なら逆クロスで決済（原典どおり） |
| トレーリング方式 | なし | なし / ATR（最高値から ATR × n） / 直近 N 本の安値・高値 / 移動平均線 / 値幅（最高値から一定の値幅）。利益が乗ったら損切りを有利な方向へ追いかける。足の確定ごとに更新し、不利な方向へは動かさない |
| トレーリング開始 | ATR × 1.0 | エントリー後の最大含み益がエントリー時の ATR のこの倍数に達したら開始。0 ならすぐ |
| トレーリングの幅 | ATR 2.0 / 5 本 / 長期MA / 5 | 方式ごとの幅（ATR 倍、本数、使う線、価格の値幅） |
| 開始後は逆クロスで決済しない | オフ | オンにすると決済をトレーリングに任せる（反対方向のサインではドテン） |
| 建値ストップ | 0（使わない） | 最大含み益が ATR × n に達したら損切りを建値へ。上乗せ（価格）も指定できる |
| 検証期間 | 全期間 | 開始・終了の日時 |

チャートの損切りラインは、最初の損切りが赤、建値ストップやトレーリングが始まると黄色に変わります。取引一覧の決済理由は「損切り」「建値」「トレール」「利確」「決済」（逆クロス）で区別できます。

### 前提（プロパティタブで変更できます）

| 項目 | 既定 | メモ |
| --- | --- | --- |
| 初期資金 | 1,000,000 | 通貨はシンボルの通貨（GBPJPY なら円、XAUUSD ならドル） |
| 注文サイズ | 資金の 100% | レバレッジ 1 倍相当。勝率・PF はサイズに関係なく同じ |
| 証拠金率 | 4% | 国内FXのレバレッジ 25 倍。100% のままだと売りがすぐマージンコールになり成績がゆがむ |
| 約定 | 次の足の始値 | 確定足でシグナル → 次の足で約定（現実に近い） |
| 手数料・スリッページ | 0 | **スプレッドは再現されない**ので、下を参考に入れてください |

**スプレッドの入れ方**：プロパティの「スリッページ」に、スプレッドの半分（片道ぶん）をティック数で入れます。
例：GBPJPY（1 ティック = 0.001 円）でスプレッド 2.0 pips = 0.02 円 = 20 ティック → スリッページ **10**。
ティックの大きさはシンボルによって違うので、シンボル情報で確認してください。

### 見るポイント

- **PF（プロフィットファクター）**：総利益 ÷ 総損失。1 を超えれば利益が出ている
- **最大ドローダウン**：資金が一番へこんだ幅。耐えられる大きさか
- **取引回数**：少なすぎると偶然の可能性が高い（目安として 100 回以上）
- 「小→大 × 自動」と「大→小 × 自動」、5/20 と 5/100、トレンドフィルターの有無などを切り替えて比べると、手法の性格がわかります
- 設定をいじりすぎると過去のチャートにだけ合った設定になりがちです。期間を前半・後半に分けて、両方で成績が崩れないか確認するのがおすすめです

## 設定比較（TradingView）

`MAMA_SelfCross_Compare.pine` は、ストラテジーと同じ売買ルールを最大 45 通り同時にシミュレーションし、成績を表で並べるインジケーターです。設定を 1 つずつ切り替えなくても、どの組み合わせが良いかを一度に比べられます。

- 比べる組み合わせ：手法 5 種（相互監視 両方・自動 / 小→大・長期 / 大→小・どちらか、パターンB、パターンC）× 長期の期間 3 種（既定 20・40・100）× 決済 3 種（逆クロスのみ / 損切り / 損切り＋ATR トレール）
- 検証の条件：数量（オンス）、手数料（1 オンスあたり片道＝スプレッドの半分）、初期資金、検証開始日、前半・後半の区切り
- 表の列：取引回数、勝率、PF、純利益、最大DD（資金比）、純利益÷最大DD、前半PF、後半PF。資金がゼロ以下になった設定は「破綻」
- 時間足はチャートの時間足。30 分足・1 時間足などに切り替えて比べる
- ストラテジーテスターとは細かい約定の扱いが違うので、数字は少しずれます。良さそうな設定を見つけたら、ストラテジーで確認してください

## MT5 での検証（EA）

`MAMA_SelfCross_EA.mq5` はストラテジーと同じ売買ルールの EA です。MT5 のストラテジーテスターで「リアルティック」を使うと、業者の実際のスプレッド（時間帯や指標発表での広がりも含む）で検証できます。1 分足のように 1 回の利益が小さい時間足は、この方法が一番正確です。

**入れ方**

1. MetaEditor で「新規作成」→「エキスパートアドバイザ（テンプレート）」→ 名前を `MAMA_SelfCross_EA` にして完了
2. 中身を全部消して `MAMA_SelfCross_EA.mq5` の内容を貼り付け、「コンパイル」（F7）

**バックテスト**（MT5 の「表示」→「ストラテジーテスター」）

| 項目 | 設定 |
| --- | --- |
| エキスパート | MAMA_SelfCross_EA |
| 銘柄 | XAUUSD（業者の銘柄名） |
| 時間足 | M1 / M30 など |
| 期間 | 例：2025.01.01 から今日まで |
| モデル | リアルティックに基づいたすべてのティック |
| 入金・レバレッジ | 300 USD・1:1000 |

初回は業者からティックデータを読み込むので時間がかかります。結果は「バックテスト」タブ（レポート）と「グラフ」タブで見られます。

**最適化（いろいろな設定をまとめて試す）**

- 「最適化」を「低速完全アルゴリズム」か「高速遺伝的アルゴリズム」にし、基準を「カスタム最大」（= 純利益 ÷ 最大ドローダウン）にする
- 「入力」タブで、試したい項目（手法・長期の期間・損切りの本数など）にチェックを入れ、開始・ステップ・終了を決める
- 「フォワード」を「1/3」などにすると、最後の 1/3 の期間を最適化に使わず、選ばれた設定がその期間でも通用するかを確認できる
- リアルティックの最適化は時間がかかるので、まず「1 分足 OHLC」で絞り込み、上位の設定だけをリアルティックで確認するのがおすすめ

**安全のための初期設定**：EA は本番口座では発注しません（起動時に止まります）。本番で使う場合だけ「本番口座での発注を許可」を true にしてください。最大スプレッド（ポイント）を入れると、スプレッドが広いときは新規エントリーしません。

## インストール

### TradingView

1. チャート下部の「Pine エディタ」を開く
2. `MAMA_SelfCross.pine` の中身をすべて貼り付ける
3. 「保存」→「チャートに追加」

**アラート**：アラート作成画面で条件にこのインジケーターを選び、

- 個別に受け取りたいとき：「買いエントリー（相互監視）」「小矢印↑」などを選ぶ
- まとめて受け取りたいとき：「alert() 関数の呼び出しのみ」を選ぶ（エントリーと決済をまとめて通知）

**ローソク足を消して MA だけ表示したいとき**：チャート設定 →「シンボル」→ 実体・枠・ヒゲのチェックを外す
（TradingView ではインジケーターからローソク足を消せないため、手動で設定します）

### MT5

1. MT5 で「ファイル」→「データフォルダを開く」
2. `MQL5/Indicators/` に `MAMA_SelfCross.mq5` をコピー
3. MetaEditor でファイルを開いて「コンパイル」（F7）
4. ナビゲーターの「インディケータ」からチャートへドラッグ

- 「ローソク足を隠す」を ON にすると、ローソク足を背景色にして MA だけのすっきりした表示になります（インジケーターを外すと元の色に戻ります）。
- アラートは足が確定したときに 1 回だけ出ます。ポップアップ・サウンド・プッシュ通知・メールを選べます（プッシュ通知とメールは MT5 側の設定が必要）。
- ファイルは UTF-8（BOM 付き）で保存しています。もし文字化けしたら、MetaEditor でファイルを開き直して保存し直してください。

## 注意

- 「確定足で判定」が ON のとき、矢印・エントリー・決済のマークは足が確定してから出るので、あとから消えたり動いたりしません。MA のライン自体は形成中の足でも動きます。
- シグナルは手法をそのまま機械的に表示したものです。トレンド判断や利確の判断（「利食いなんか適当に飽きたらとかでもいい」）は自分で行ってください。
- 実際の売買に使う前に、必ず過去チャートやデモ口座で確認してください。投資判断は自己責任でお願いします。
